# 执行稳定性与测试范围修复（2026-09-14）

针对任务 `355e43da-861b-412d-b52c-ad1b5b7a8f2a` 中确认的问题，修复集中在以下路径。现有执行历史和 Spec 保持原样。

## 执行状态与清理

执行阶段、已分配账号及其别名、业务对象归属、初始状态、提交回执、清理状态存放在现有 JSON 字段 `executionPolicy.executionState`。控制面在当前执行租约和 fencing token 校验之后，同时更新 Run 与下一次恢复使用的 Agent snapshot。已校验的验收结果和证据通过 `verificationCheckpoint` 保存，同一次尝试和同一账号的人工恢复不会清空已经完成的验收；新尝试或换账号会重新验证。

对于账号加类型的配置记录，只有同一 API 资源上的筛选空结果、完成的成功提交回执、随后查询到的记录三者对应，才自动确认 `CREATED_THIS_RUN`。HTTP 200、尚未完成的响应体、业务错误响应、其他 API 的同名记录都不能单独证明归属。恢复后已确认的对象不能降级为外部冲突，也不能覆盖原始状态。

列表先返回、创建响应体后到达时，记录及其证据暂存在 `pendingRecords`，不会标为原有数据。回执补齐后自动确认归属并生成清理项，跨人工恢复仍有效；回执明确失败则不授予创建归属。正常结束前须先确认这些待定记录的回执。

编辑已有数据时，通过 `record_progress.executionState` 保存初始状态和恢复动作。正常结束前有待清理对象会先进入清理；临近预算上限或首次重复操作停止时，留出一次清理机会。完成清理必须引用新的核对证据。无法安全处理时保存 `BLOCKED` 和原因，页面展示具体记录与待处理动作。进程丢失、模型全部不可用或预算完全耗尽时，不能保证业务清理完成；保存待清理状态并保留原停止原因。

## 账号隔离

静态 Spec 中明确标注的账号和人工提供的账号使用同一套预留。预留在业务操作前执行，并在同团队的数据库事务锁下检查环境、账号及已观察到的手机号/UUID 别名。识别到别名冲突后停止后续写操作；服务端确认冲突解除时，执行器同步清除本地标记。未清理的旧账号记录不会因换了新账号而解除占用。已结束用例在浏览器确认关闭、已跟踪对象全部清理后允许复用；没有业务记录时，须依据启动与命令审计确认未写入，或存在明确的 NO_WRITE 核实记录。没有分配过浏览器且没有写入记录的任务也可释放。空台账、浏览器仅断开、允许重试均不能独立证明没有写入。历史人工分配记录使用相同释放规则。

`record_progress` 只保存当前账号下的执行进度，不分配或切换账号；非法变更在申请占用前拒绝。换账号继续通过 Spec 或 TEST_ACCOUNT 人工输入入口处理。

人工弹窗支持“提供新账号”和“提交处置意见”。账号允许手机号、UUID、邮箱或用户 ID；说明文字不能作为账号提交。处置意见保留当前账号，交由 Agent 结合实际归属和证据处理，不代表可以删除其他用例的数据。

## Spec 与证据

多语言测试须明确声明 `testScope=LOCALIZATION`，并用 `issueEvidence` 引用 Linear Issue 标题或描述中的明确要求。生成阶段和 API 接收阶段均检查。PR 的翻译文件、英文枚举、Route Spec 多语言标签不能扩展测试范围。普通英文界面的功能验证不受影响。新增与独立编辑按前置条件拆分；仅在来源要求同一记录完整生命周期时合并。准备和清理不充当产品验收。

请求参数、请求体、响应数据验收须要求 NETWORK 证据。浏览器保留有边界、已脱敏的同源或执行节点白名单覆盖的跨域业务 JSON 请求体与响应体，认证接口、非 JSON 和过大载荷不采集。实际浏览器测试覆盖请求体保留、敏感字段脱敏和 NETWORK artifact。JSON 验收按结构比较，忽略排版与对象键顺序，保留布尔类型、数组顺序和字符串内容的区别。

## 运行与展示

- 自定义开关的 role、aria-checked、aria-pressed 等状态进入 DOM 观察和操作状态比较。
- 模型明确不存在或无权限时立即进入冷却，不继续消耗五次瞬时错误重试；冷却以不含明文凭据的配置摘要为键，人工恢复可继承。普通瞬时失败仍按每模型最多五次尝试，单次默认 300 秒，整体执行预算继续生效。
- 暂停预算的人工等待使用独立配置时限；恢复时仍按既有策略返还等待时间。
- 飞书 Bot Not Enabled 归类为配置错误，终止同一通知的重复投递，保留实际尝试次数，并在人工弹窗展示原因。飞书应用的机器人能力和已发布版本仍需在开放平台配置；本地代码无法开启远端应用能力。
- 停止原因、写入状态和待清理业务对象分别展示。
- 视频编码使用有上限的时长和分辨率，为两次编码及 Chromium 启动留出空间。长任务概览最多均匀抽取 60 帧，保留首尾帧；所有原始步骤截图继续保存。实际浏览器关闭流程验证生成非空视频。
